Error: ENOENT: no such file or directory, open 'does-not-exist.txt'

Error: ENOENT: no such file or directory, open 'does-not-exist.txt'

Polly Glot says: Wetin happen?

What this means

Node tried to open does-not-exist.txt, but no file exists at that path. Check the path, the working directory, and whether the file was created.

How Sabicode explains it

street

🦜 Error: Node no find does-not-exist.txt
Wetin happen: You ask Node to open does-not-exist.txt, but that file no dey for that path.
Wetin to do: Check the path and the folder wey you dey run from: path.join(__dirname, "does-not-exist.txt")
Learn am: ENOENT mean "Error NO ENTry". The file or folder no exist for the path.
