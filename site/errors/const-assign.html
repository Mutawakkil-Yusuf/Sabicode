TypeError: Assignment to constant variable.

TypeError: Assignment to constant variable.

Polly Glot says: Wetin happen?

What this means

A variable created with const cannot be reassigned. The value was locked when it was declared, so the later assignment throws a TypeError.

How Sabicode explains it

street

🦜 TypeError: You try change const
Wetin happen: You use const lock age, then you wan change am. E no go gree.
Wetin to do: If the value go change, use let: let age = 20;
Learn am: "constant" mean value wey no dey change.
