SyntaxError: Unexpected token ';'

SyntaxError: Unexpected token ';'

Polly Glot says: Wetin happen?

What this means

The parser found ; where it expected something else. A missing comma, bracket, or quote earlier in the line usually causes this.

How Sabicode explains it

street

🦜 SyntaxError: JavaScript no expect ;
Wetin happen: JavaScript see ; for place wey e no expect am. Something before am dey miss or dey extra.
Wetin to do: Look the line wey the error point to, and the one before am. Check for missing comma, bracket or quote.
Learn am: A "token" na one small piece of code, like a word, bracket or symbol.
