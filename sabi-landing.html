Error messages assume you already know the jargon

Learning to code is hard enough without decoding red text in a second language. Sabicode keeps the original error and adds a plain explanation in the language you think in.

Run your file

Use sabi instead of node. Nothing else changes.

sabi run app.js

Read am

The original error stays. A plain explanation and a fix appear under it.

Wetin happen: ...
Wetin to do: ...

Learn am

Every explanation ends with the real English term, so you recognize it at work.
